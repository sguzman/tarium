# Project gallery

This gallery belongs **inside the independent project**, not in the Tarium hub.

Maintain a human-readable index of representative publicly releasable screenshots, figures, outputs, examples, or demonstrations relevant to the project's work. Pair it with `index.json` for machine-readable discovery. Gallery entries should include a title, description, local or public asset path, source/provenance, and licensing information.

It is valid to have zero entries early in development. Do not invent examples or import private images, internal screenshots, private archives, chat fragments, or unlicensed media. Assets needed to understand core results should be bundled or openly and reliably available.
